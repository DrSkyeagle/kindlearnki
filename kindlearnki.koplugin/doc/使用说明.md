# Kindlearnki 使用说明

适用：越狱的 Kindle Voyage（KOReader ≥ v2026.07.1，`kindlepw2` 包）
版本：0.3.1

---

## 1. 安装

1. 把 `kindlearnki.koplugin` 整个目录放到 Kindle 的 `koreader/plugins/` 下；
2. 安全弹出、拔线，重启 KOReader；
3. 入口：主菜单 → **工具**（扳手）标签页最底部 → **Kindlearnki**；
   也在 **主菜单** 标签页最底部。可绑成手势（设置 → 手势 → 手势管理）。

> 插件不会碰 `koreader/data/ankiweb/`（旧插件的数据），两者可以并存。

## 2. 第一次使用

1. **登录**：工具 → Kindlearnki → 立即同步 → 输入 AnkiWeb 邮箱与密码。
   密码只用于换取同步密钥（hkey），**不会保存**；设备上只留 hkey。
2. **整库下载**：首次没有本地库，插件会自动从 AnkiWeb 下载整库（约 5 MB）。
3. **开始复习**：工具 → Kindlearnki → 开始复习 → 选牌组。

## 3. 复习

- 正面：正文 + 底部通栏「显示答案」。
- 背面：正文 + 四个评分：**重来 / 困难 / 记住 / 太简单**，按钮上显示下次间隔。
- **牌组页也用 PagePress 翻页**（`PgFwd` 下一页 / `PgBack` 上一页），右下角显示 `2/3`，点它也能翻。
- 牌组页只显示到**二级**牌组；三级及更深的牌组不单列，卡片数已计在二级牌组里。
- **翻页键（PagePress）在复习页只翻卡片正文的上下页**（长卡片用；到顶/到底就停），
  不负责翻面、也不评分——这是刻意的：卡片经常有好几屏，而 e-ink 没有滚动。
- 这两个键**在两种启动方式下都有效**：KOReader 以 no-framework 方式启动（`STOP_FRAMEWORK=yes`）
  时由 KOReader 自己打开 `com.lab126.deviced` 的 `fsrkeypadEnable`；普通启动（Kindle 原框架还在跑、
  KOReader 从 KUAL 或菜单里点起来）时由本插件打开同一个开关——不开的话驱动根本不把按键送进
  `/dev/input/event2`，表现就是"实体键没反应"。0.3.3 之前只有前一种情况能用。
- 显示答案、评分都用触摸：底部黑条显示答案，背面四列评分。
- 右上角 **×** 退出（Voyage 没有返回键）。
- 正文也能点：多页时点一下翻下一页，最后一页再点 = 显示答案（仅正面）。
- 卡片字号按屏幕自适应（约每行 26 个汉字），Anki 模板里写死的 `font-size` 会被忽略。

评分语义与 Anki v3 一致（学习步、ease、leech、兄弟卡 bury、凌晨 4 点跨天、每日限额）。

## 4. 同步

- **打开时拉、复习结束后推**：进入插件会尝试拉取（Wi-Fi 未就绪时 2 秒内放弃，不阻塞复习）；
  每次复习会话结束时自动推送。
- 手动：立即同步。
- **手机端改过牌组/笔记类型时不会打断你**：插件会自己接管云端那一份（下载整库），
  把本机还没推上去的复习按修改时间合并回去，然后继续同步把它们推上去——不需要
  你选方向，也不会丢复习。整库同步只在你想主动重建时才用（菜单里仍保留两个方向：
  下载云端覆盖本地 / 上传本地覆盖云端）。
- 只有一次同步里连续出现两次结构变化才会放弃并报错（避免死循环）。
- 断网、超时、hkey 失效、时间偏差都会显示可行动提示，不会留下半截库。

## 4.1 从旧名字（kindleanki）升级

1. **删除**旧的 `koreader/plugins/kindleanki.koplugin/`（两个插件目录同时存在会互相
   抢 `core.*` 模块，新插件会报 `attempt to call field 'migrate_legacy'`）。
2. 放入 `kindlearnki.koplugin/` 后重启 KOReader。
3. 首次启动自动把 `koreader/kindleanki/collection.anki2`（含 WAL）与
   `koreader/settings/kindleanki.lua` 复制到新路径；日志里会出现
   `migrated kindleanki data (collection=true settings=true)`。

## 4.2 图片与媒体（手动放入）

插件**不联网下载媒体**。图片能不能显示，只看 Kindle 上这个文件夹里有没有同名文件：

| 设备内部路径 | 连电脑后看到的路径 |
|---|---|
| `/mnt/us/koreader/kindlearnki/media/` | `Kindle/koreader/kindlearnki/media/` |

这个目录在第一次启动时自动创建，一直是空的——**不放文件，卡上就只有占位符**。

### 怎么放

1. 在电脑上找到 Anki 的媒体文件夹（就是 `collection.media`）：
   - Windows：`%APPDATA%\Anki2\<用户名>\collection.media`
   - macOS：`~/Library/Application Support/Anki2/<用户名>/collection.media`
   - Linux：`~/.local/share/Anki2/<用户名>/collection.media`

   也可以在 Anki 里点：**工具 → 检查媒体 → 打开文件夹**。
2. Kindle 连电脑，打开 `Kindle/koreader/kindlearnki/media/`。
3. 把 `collection.media` 里的**文件**全选复制进去：平铺，不要建子目录，不要改文件名。
   卡片里的 `<img src="paste-1234.jpg">` 找的就是这个名字。
4. 安全弹出、拔线；已经开着的复习页退出重进（图片是渲染时读的，不会自己刷新）。

> 只放图片就够了。音频（`[sound:...]`）和视频本来就不支持，放进去也不会播。

### 怎么确认成功

- 图片卡显示真图；**卡上出现 `[image]` 就说明还缺文件**——这是 MuPDF 的缺图占位符，
  不是"插件不支持图片"。**不放媒体文件也没关系**：插件不会在复习时提醒你，卡片照常显示。
- 每次同步结束的消息框里会带一句媒体目录，方便你随时照着放。

### 换成自己的目录（可选）

不想每次复制，可以直接指向 Kindle 上已有的文件夹。比如把 `collection.media`
整个复制到 `documents/` 下，然后打开 `koreader/settings/kindlearnki.lua`，在
`return { ... }` 那张表里加一行（改完重启 KOReader 才生效）：

```lua
media_dir = "/mnt/us/documents/collection.media",
```

留空、写错、或写成 `/` 都会退回默认的 `koreader/kindlearnki/media/`。插件只读这个
目录，不会创建也不会修改它。

### 不会显示的情况

- **CSS 背景图**（`background-image: url(...)`）被渲染器主动去掉：缺图在 e-ink 上会
  变成破图框、把整张卡顶歪，所以一律不画。
- 少数模板用子目录（`src="images/a.png"`）：那 `media/` 里也要有同名子目录。

## 4.3 清理与换号

菜单里有两个破坏性操作，点下去都会先弹确认框。

| 菜单项 | 删什么 | 留什么 | 什么时候用 |
|---|---|---|---|
| **删除卡片库** | `koreader/kindlearnki/collection.anki2`，连同 `-wal` / `-shm` / `.bak` | 登录状态（hkey） | 同步一直失败、想强制从云端整库重下；或卸载前清干净 |
| **注销本地账户** | 本机 hkey **和** 本地卡片库 | 设置文件里的其它项 | 换 Anki 账户 |

- 删库后下一次同步会自动整库下载（约 5 MB），不用手动做什么。
- 注销后下一次同步会要求重新登录。**它会连带删库**：只删钥匙不删库的话，换号后首次同步
  会把旧账户的卡片和复习记录合并进新账户。
- 想撤销设备密钥也可以走 AnkiWeb 网页版 → 设置 → 已登录设备。

## 5. 数据位置

| 内容 | 路径 |
|---|---|
| 本地库 | `koreader/kindlearnki/collection.anki2` |
| 设置 / hkey | `koreader/settings/kindlearnki.lua`（hkey 为明文） |
| 整库备份 | 同步时自动生成 `collection.anki2.bak` |
| 卡片图片 | `koreader/kindlearnki/media/`（手动放入，见 §4.2） |

想撤销设备密钥：AnkiWeb 网页版 → 设置 → 已登录设备。

## 6. 明确的限制

| 限制 | 说明 |
|---|---|
| 不支持音频 / JS / 数学公式 | 显示为「（音频）」或降级为文本 |
| 输入答案型卡片 | 降级为自评（正面显示提示，背面自己评分） |
| 不做浏览 / 编辑 / 统计 / 导入 | 本插件只做复习与同步 |
| 不支持筛选牌组 / 自定义学习 / FSRS | v3 核心语义，不含这些 |
| 图片 | 支持显示；**媒体不联网同步**，需手动把 `collection.media` 放进 `koreader/kindlearnki/media/`（§4.2），缺图显示 `[image]` |
| 每张卡一个事务 | 强杀 KOReader 不丢已答的卡 |

## 7. 排查

| 现象 | 处理 |
|---|---|
| 菜单里找不到 | 插件项在标签页**最底部**；确认「工具 → 帮助 → 插件管理」里已勾选 |
| 打开就提示「还没有本地库」 | 先登录并同步一次 |
| 登录后同步报「登录已失效」 | 重新登录（hkey 过期或被其它设备顶掉） |
| 同步报「时间相差太大」 | Kindle 时钟漂移，联网后自动校准再试 |
| 卡片空白 | 该卡内容只有图片/音频等不支持的元素；换桌面端查看 |
| 其它异常 | 看 `koreader/crash.log` 里 `kindlearnki:` 开头的行 |
